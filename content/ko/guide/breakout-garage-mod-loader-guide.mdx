## 모드 로더가 Breakout Garage에서 실제로 하는 일

게임은 폐쇄형 패키지로 제공됩니다. 엔진은 개발자가 내부에 넣은 에셋과 스크립트만 읽고, 폴더에 있는 다른 것은 무시합니다. 모드 로더는 그 시작 순서에 스스로를 삽입하고 게임이 외부 파일을 읽도록 알려 줍니다.

실제로 로더는 세 가지 일을 합니다.

- **실행 과정에 후킹하여** 외부 코드가 게임의 메인 로직을 넘겨받기 전에 실행되게 합니다.
- **정의된 순서로 모드 파일을 로드합니다.** 그래서 한 모드가 다른 모드를 덮어쓸 수 있습니다.
- **로그 파일을 작성하여** 무엇이 로드되었고, 무엇이 실패했으며, 그 이유가 무엇인지 정확히 기록합니다.

그 로그는 모딩에서 단일 파일로 가장 가치 있는 파일입니다. 모드가 조용히 아무것도 하지 않을 때, 로그는 보통 몇 초 안에 "파일을 찾을 수 없음" 또는 "의존성 누락"이라고 말해 줍니다.

| 로더 구성 요소 | 하는 일 | 일반적인 위치 |
|---|---|---|
| 로더 코어 | 게임의 메인 코드 전에 시작해 런타임을 준비 | 게임 루트 폴더 |
| 모드 폴더 | 각 모드를 보관하며, 보통 모드당 폴더 또는 파일 하나 | 첫 실행 시 생성됨 |
| 구성 파일 | 텍스트 편집기에서 편집할 수 있는 모드별 설정을 저장 | 구성 또는 사용자 데이터 폴더 |
| 로그 파일 | 로드 순서, 오류, 누락된 의존성을 기록 | 로더 또는 게임 로그 디렉터리 |
| 의존성 라이브러리 | 여러 모드가 의존하는 공유 코드 | 모드 폴더 또는 로더 디렉터리 |

커뮤니티 보고서는 일관되게 같은 패턴을 보여 줍니다. "고장 난" 모드 대부분은 사실 고장 난 것이 아닙니다. 잘못된 폴더에 있거나, 이름이 잘못되었거나, 플레이어가 설치하지 않은 공유 라이브러리를 기다리고 있을 뿐입니다.

마지막으로, 싱글 플레이용으로 모딩할지 멀티플레이어용으로 모딩할지 미리 결정하세요. Breakout Garage에 경쟁 또는 공유 모드가 있다면 클라이언트 측 모드에 위험이 따른다고 가정하고, 외형이 아니라 게임플레이를 바꾸는 것을 설치하기 전에 규칙을 확인하세요.

## Breakout Garage 모드 로더 단계별 설치

아래 설치 순서는 이 **Breakout Garage 모드 로더 가이드**에서 대부분의 사람이 서두르는 부분이며, 동시에 올바르게 하기 가장 쉬운 부분입니다.

1. **게임을 완전히 종료하세요.** 작업 관리자를 확인하세요 — 백그라운드 프로세스가 파일을 잠가 부분 설치를 일으킬 수 있습니다.
2. **게임의 루트 폴더를 찾으세요.** 메인 실행 파일이 들어 있는 폴더이며, 바탕 화면의 바로가기가 아닙니다.
3. **공식 출처에서 로더를 다운로드하세요.** 제3자 미러는 멀웨어가 함께 포함되는 흔한 경로입니다.
4. **로더 자체 지침을 먼저 읽으세요.** 모든 로더에는 특이 사항이 있으며, 해당 문서는 이 가이드를 포함한 일반 가이드보다 우선합니다.
5. **로더를 루트 폴더에 압축 해제하세요.** 문서에서 하라고 하지 않는 한 하위 폴더 안에 중첩하지 마세요.
6. **게임을 한 번 실행한 뒤 종료하세요.** 이 첫 실행에서 모드 폴더, 구성 파일, 로그가 생성됩니다.
7. **폴더가 생겼는지 확인하세요.** 생기지 않았다면 로더가 연결되지 않은 것이므로, 모드를 추가하기 전에 여기서 멈추고 문제를 해결하세요.
8. **모드 하나를 설치하세요.** 제작자가 지정한 구조에 따라 모드 폴더에 복사하세요.
9. **실행하고 확인하세요.** 다른 것을 추가하기 전에 로그에서 성공적인 로드 줄을 확인하세요.

| 단계 | 작업 | 성공 지표 |
|---|---|---|
| 1–2 | 게임 종료, 루트 폴더 찾기 | 게임 실행 파일이 보임 |
| 3–5 | 로더 다운로드 및 압축 해제 | 로더 파일이 실행 파일 옆에 있음 |
| 6–7 | 첫 실행 후 종료 | 모드, 구성, 로그 폴더가 존재 |
| 8 | 모드 하나 추가 | 모드 파일이 올바른 폴더에 나타남 |
| 9 | 다시 실행하고 로그 읽기 | 로그에 모드가 오류 없이 로드되었다고 표시됨 |

모드를 한 번에 하나씩 추가하는 것은 느리게 느껴지지만, 추측 게임을 5초 진단으로 바꿔 줍니다. 문제가 생기면 어떤 파일이 원인인지 정확히 알 수 있습니다.

## 모드 정리, 테스트 및 업데이트

설치에서 멈추는 **Breakout Garage 모드 로더 가이드**는 절반만 유용합니다. 장기적인 안정성은 설정을 어떻게 정리하고 유지 관리하느냐에서 나옵니다.

**로드 순서가 중요합니다.** 두 모드가 같은 에셋이나 값을 편집하면 마지막에 로드된 모드가 보통 이깁니다. 대부분의 로더는 알파벳순 또는 파일 이름의 우선순위 번호로 읽으므로, 파일 이름을 의도적으로 지정하면 제어할 수 있습니다.

**목적별로 그룹화하세요.** 외형 모드, 편의성 개선, 게임플레이 대개편은 다르게 작동하고 충돌 빈도도 다릅니다.

| 모드 유형 | 충돌 위험 | 테스트 방법 |
|---|---|---|
| 외형(텍스처, UI 스킨) | 낮음 | 3~4개 묶음으로 설치 |
| 편의성(단축키, 카메라) | 낮음~중간 | 입력을 건드리면 개별 테스트 |

| 의존성 라이브러리 | 중간 | 이를 필요로 하는 모드보다 먼저 설치 |
| 토탈 컨버전 | 매우 높음 | 별도의 깨끗한 게임 복사본 유지 |

**게임 업데이트 후에는 항상 모드가 깨진다고 가정하세요.** 업데이트는 내부 코드를 바꾸고, 로더는 다시 연결되기 전에 일치하는 업데이트가 필요한 경우가 많습니다. 안전한 절차는 다음과 같습니다. 모드 폴더를 백업하고, 게임을 업데이트하고, 로더를 업데이트한 다음, 모드를 소규모 그룹으로 다시 도입하세요. 모든 모드와 버전을 나열한 텍스트 파일을 유지하세요 — 몇 달 뒤 문제가 생기면 그 목록이 한 시간의 추측을 아껴 줍니다.

- **활발한 커뮤니티가 있는 출처에서만 다운로드하세요.** 댓글과 업데이트 이력이 있는 모드 페이지는 익명 파일 배포보다 훨씬 안전합니다.

- **안티치트에 주의하세요.** 게임이 커널 수준 안티치트를 사용한다면, 주입된 코드는 싱글 플레이에서도 밴을 유발할 수 있습니다.
- **멀티플레이어 규칙을 존중하세요.** 외형 모드는 보통 허용되지만, 게임 로직을 바꾸는 것은 그렇지 않습니다.

플레이어 경험에 따르면 대부분의 밴은 시각적 교체가 아니라 네트워크 동작이나 메모리 값을 수정하는 모드에서 발생합니다. 어떤 모드가 안전한지 확실하지 않다면 설치 전에 커뮤니티에 물어보세요 — 누군가는 거의 확실히 이미 시도해 보았습니다.

## Breakout Garage 모드 로더 FAQ

**Breakout Garage 모드 로더 가이드만으로 완전한 초보자에게 충분한가요?**
네. 파일을 폴더에 복사해 붙여넣고 텍스트 로그를 읽을 수 있다면 게임을 모딩할 수 있습니다. 필요한 기술은 신중한 파일 배치와 테스트할 때의 인내심뿐입니다.

**모드 로더를 사용하면 세이브 파일이 깨지나요?**
그 자체로는 아닙니다. 세이브는 보통 모드가 게임 데이터를 바꾼 뒤 그 모드 없이 해당 세이브를 로드할 때 깨집니다. 첫 모드 플레이 전에는 항상 세이브를 백업하세요.

**게임 업데이트 후 모드가 작동을 멈추는 이유는 무엇인가요?**
